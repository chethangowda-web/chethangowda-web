## `01 // SYSTEM_IDENTITY`

**Not just another application. A system worth understanding.**

</div>

I'm a Computer Science Engineering student building at the intersection of **AI engineering, backend systems, and full-stack development**.

My focus is understanding how software works beneath the interface: how agents reason through tasks, how services exchange information, how data flows through a system, and how we evaluate whether an AI-powered feature actually works.

```yaml
identity:
  role: "CSE Student | Aspiring AI / Software Engineer"
  primary_focus: "Applied AI + Software Engineering"

engineering_interests:
  - Multi-agent orchestration
  - LLM applications and RAG
  - API and backend architecture
  - System design and distributed systems

current_mission:
  - Build meaningful engineering projects
  - Strengthen DSA and system design
  - Prepare for product-company internships

principle: "Understand deeply. Engineer deliberately."
```

> I don't want to build AI demos that merely look impressive. I want to understand the architecture, test the behavior, and build systems that solve real problems.
